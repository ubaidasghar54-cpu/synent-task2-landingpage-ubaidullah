# Infinix Smart 20 Product Landing Page

A responsive, educational product landing page for the Infinix Smart 20. This is an internship project, not an official Infinix website.

## Features

- Hero section and a color and memory selector that updates the product image, configuration, and price
- CSS-only hero slideshow cycles through the four phone colors and respects reduced-motion preferences
- Staggered hero text entrance and subtle color animation on the eyebrow and headline
- Four feature cards for the display, battery, cameras, and durability
- Footer with quick links, contact and social placeholders, and an educational-project disclaimer
- Responsive layout from narrow mobile screens through tablets, laptops, and wide desktops
- Touch-friendly navigation targets and no horizontal overflow on tested screen widths
- Keyboard focus styles and reduced-motion support

## Product details

The page uses the verified product details provided for this project, plus the memory variants and prices supplied for this page.

- 4+4 GB RAM + 128 GB storage: approximately PKR 46,999 to PKR 49,999
- 4 GB RAM + 64 GB storage: approximately PKR 38,999 to PKR 39,999

Both configurations list their display resolution, processor, cameras, battery and charging, software, IP64 rating, dedicated microSDXC slot, side-mounted fingerprint sensor, and IR blaster.

## Technology

- HTML
- CSS
- System UI font stacks to avoid external font requests

No JavaScript, external font requests, or CSS frameworks are used. Native radio inputs and CSS handle the product selection.

## Project files

```text
index.html
css/
  style.css
image/
  images.jfif
  images (1).jfif
  images (2).jfif
  images (3).jfif
```

The product photos are stored in `image/`. The hero uses the Shadow Black photo, and the configuration selector displays the photo matching the selected color.

## How to run

Open `index.html` in a web browser. No package installation or build step is required.
